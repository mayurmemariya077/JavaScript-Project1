## ✨ Features

This project contains **20 JavaScript mini projects**:

### 🔢 Basic JavaScript Projects

1. 🔍 **Prime Number Checker**
   - Checks whether a number is prime or not.

2. 🎂 **Age Eligibility Checker**
   - Checks whether a person is eligible based on age.

3. 🛍️ **Shopping Discount Calculator**
   - Calculates discount and final shopping amount.

4. 🔄 **Reverse Number**
   - Reverses the entered number.

5. 🚦 **Traffic Signal Simulator**
   - Simulates Red, Yellow, and Green traffic signals.

6. ⚡ **Even or Odd Checker**
   - Determines whether a number is even or odd.

7. 📊 **BMI Calculator**
   - Calculates BMI and displays the BMI category.

8. 🎯 **Age Calculator**
   - Displays the entered age with validation.

9. ✖️ **Factorial of a Number**
   - Calculates the factorial of a given number.

10. 💱 **Currency Converter**
    - Converts USD into INR using a fixed conversion rate.

11. 🔤 **Vowel or Consonant Checker**
    - Checks whether the entered character is a vowel or consonant.

---

### 📚 JavaScript Array Projects

12. ➕ **Array Sum Calculator**
    - Calculates the sum of all numbers in an array.

13. 🏆 **Find Largest Number**
    - Finds the largest number from an array.

14. 🔁 **Reverse Array**
    - Reverses the elements of an array.

15. 🔢 **Count Even and Odd Numbers**
    - Counts the total even and odd numbers in an array.

16. 🔽 **Find Smallest Number**
    - Finds the smallest number from an array.

17. 🔎 **Search Element in Array**
    - Searches for a specific element inside an array.

18. 🥈 **Find Second Largest Number**
    - Finds the second largest unique number in an array.

19. 🧹 **Remove Duplicate Array**
    - Removes duplicate values from an array.

20. 📈 **Array Average**
    - Calculates the average of array elements.
